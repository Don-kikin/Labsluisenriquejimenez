# Prueba de Servidor Local: Hola Cohorte 73

Este proyecto contiene un documento HTML básico diseñado para verificar la correcta instalación y funcionamiento de un servidor web local (Apache). 

## Propósito

El archivo `Luisch73.html` sirve como página de aterrizaje (landing page) de prueba. Su objetivo principal es confirmar que el entorno de desarrollo local está activo, sirviendo archivos estáticos correctamente a través del puerto 80, y que las rutas del directorio público son accesibles desde el navegador.

   http://localhost/Luisch73.html
